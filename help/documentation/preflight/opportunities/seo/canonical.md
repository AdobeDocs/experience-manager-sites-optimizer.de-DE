# Kanonische Prüfung

Der Audit **Canonical** überprüft den kanonischen Link auf Ihrer Seite. Ein korrekter kanonischer Link teilt Suchmaschinen mit, welche URL die autoritative Version einer Seite ist, wodurch Probleme mit doppelten Inhalten vermieden werden können. Audit kennzeichnet kanonische Links, die fehlen oder falsch sind.

Wenn der Audit Chancen findet, beschreibt jede das Problem und die empfohlene Änderung. Informationen zum Überprüfen und Beheben von Opportunities finden Sie unter [Audit results in Preflight](../../audit-results.md).
