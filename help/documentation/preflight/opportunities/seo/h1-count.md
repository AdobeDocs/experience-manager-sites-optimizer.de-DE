# H1-Zählungsprüfung

Der **H1-** überprüft die Anzahl der H1-Überschriften auf Ihrer Seite. Eine Seite sollte im Allgemeinen über ein einziges, beschreibendes H1 verfügen, das ihren Inhalt zusammenfasst. Fehlende oder mehrere H1-Überschriften können die Seitenstruktur und die Suchmaschinenoptimierung schwächen.

Wenn der Audit Chancen findet, beschreibt jede das Problem und die empfohlene Änderung. Informationen zum Überprüfen und Beheben von Opportunities finden Sie unter [Audit results in Preflight](../../audit-results.md).
